# My Builder Page

## What it is

A personal portfolio website I built from scratch to show my projects and some of the things I work on.

## What it does

The site has a home page and a projects page where you can open individual projects. Project pages can show a description, tags, images, GitHub links, and source code.

It also has responsive layouts, a loading screen, background animations, and a copy-code button.

## What I learned

I learned more about HTML, CSS, and JavaScript, especially responsive design, DOM manipulation, animations, and loading content dynamically with JavaScript.
